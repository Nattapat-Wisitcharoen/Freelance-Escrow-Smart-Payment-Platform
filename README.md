# Freelance Escrow & Smart Payment Platform

## ขั้นตอนการทำงาน 

### 1. ผู้ว่าจ้างสร้างข้อตกลงการจ้างงาน 
ผู้ว่าจ้างระบุ Wallet Address ของฟรีแลนซ์, รายละเอียดงาน, ค่าจ้าง และระยะเวลาทำงาน เพื่อสร้างข้อตกลงลงบนบล็อกเชน

![Step 1 - Create Job](https://github.com/user-attachments/assets/d4b961cb-c831-4d62-98ed-726afa58dd6c)

### 2. ผู้ว่าจ้างฝากเงินค่าจ้าง 
ผู้ว่าจ้างทำการโอนเหรียญ (ETH) เข้าไปล็อกไว้ใน Smart Contract เพื่อเป็นการการันตีว่ามีเงินจ่ายแน่นอนเมื่อจบงาน

![Step 2 - Deposit Funds](https://github.com/user-attachments/assets/4cc8b1f9-0b7d-40d3-be9a-2f2a91f09246)

### 3. ฟรีแลนซ์ส่งมอบงาน
เมื่อฟรีแลนซ์ทำงานเสร็จสิ้น สามารถนำลิงก์ผลงาน (URL/Hash) มาส่งมอบในระบบ เพื่อให้ผู้ว่าจ้างตรวจสอบ

![Step 3 - Submit Work](https://github.com/user-attachments/assets/816c9bb5-9e93-473a-9760-3608dba20648)

### 4. ผู้ว่าจ้างอนุมัติและจ่ายเงิน 
หากผลงานถูกต้อง ผู้ว่าจ้างกดยืนยันอนุมัติงาน ระบบจะทำการโอนเงินที่ล็อกไว้ไปให้ฟรีแลนซ์โดยอัตโนมัติ (จบการทำงาน)

![Step 4 - Approve and Pay](https://github.com/user-attachments/assets/407c17d1-ed72-4e31-84c9-9fe201c30b8f)

### 5. การแจ้งข้อพิพาท 
ในกรณีที่มีปัญหา (เช่น ผู้ว่าจ้างไม่ยอมตรวจงาน หรือ ฟรีแลนซ์ส่งงานไม่ตรงสเปก) **ทั้งผู้ว่าจ้างและฟรีแลนซ์** สามารถกดปุ่มแจ้งข้อพิพาทได้ เพื่อระงับการทำธุรกรรมชั่วคราว

![Step 5 - Dispute](https://github.com/user-attachments/assets/2da423e3-385d-49f3-a44c-1e48b6bcaee0)

### 6. การตัดสินข้อพิพาทโดยแอดมิน 
ผู้ดูแลระบบ (Admin) จะเข้ามาตรวจสอบปัญหาและเป็นผู้ตัดสินใจ 
- หากผู้ว่าจ้างชนะ: เงินจะถูก **คืน (Refund)** ให้ผู้ว่าจ้าง
- หากฟรีแลนซ์ชนะ: เงินจะถูก **จ่าย (Pay)** ให้ฟรีแลนซ์
